# Roadmap

This is the proposed roadmap of development.

---

## 0.01

Initial version that validates the main architecture and integrates the main
libraries (SDL, ImGui, JSON, spdlog).

- Basic time control implemented to check simulation time running as an
  architecture for validation.

---

## 0.02

Planetary mechanics implementation. This version performs:

- **a)** Computation of orbital mechanics for planets.
- **b)** Creation and reading of Sol system bodies from a data file.
- **c)** Basic painting of the Sol system in a 2D projection.
- **d)** GUI console for debug.
- **e)** Basic map controls (move, zoom).

---

## 0.03

Planetary information display. This version includes:

- **a)** Selection of a system body on the map.
- **b)** Display of system body information.
- **c)** Inclusion and display of system body images for the Sol system.
- **d)** Generation of minerals for the Sol system.
- **e)** Display of minerals for the Sol system.
