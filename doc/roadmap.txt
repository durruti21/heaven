This is the proposed Road Map of development

0.01 - Initial version that validates main architecture and integrates main libraries (SDL, ImGui, Json, Spdlog)
       Basic time control implemented to check simulation time running as an arquitecture for validation.
0.02 - Planetary mechanics implementation. This version performs:
       a) Computation of Orbital mechanics for planets
       b) Creation and reading of Sol system bodies from a data file
       c) Basic painting of sol system in a 2D projection.
       d) GUI console for debug
       e) Basic map controls (Move, Zoom)
0.03 - Planetary information display. This version includes:
       a) Selection of a system body on the Map
       b) Display of system body information
       c) Inclusion and display of system body image for Sol system
       d) Generation of Minerals for Sol system
       e) Display of Minerals for Sol System
